# Live Calendar List

YouTube で登録しているチャンネルのライブ配信予定を、一覧とカレンダーでまとめて確認できる Android アプリです。

本アプリは個人の開発者が提供する非公式のアプリであり、YouTube および Google LLC が提供・承認・推奨するものではありません。「YouTube」は Google LLC の商標です。

## 主な機能

* **登録チャンネルの取り込み**：Google アカウントでログインすると、YouTube で登録しているチャンネルの一覧を取り込みます。表示するチャンネルはアプリ内で選べます。
* **配信予定の一覧・カレンダー表示**：選んだチャンネルのライブ配信予定を、一覧とカレンダーで確認できます。配信予定から YouTube の配信ページを開けます。
* **配信開始前の通知**：配信の 10 分前・30 分前・60 分前から、通知のタイミングを選べます。
* **視聴履歴**：アプリから開いた配信を記録します。通常は 1 ヶ月前まで、リワード広告を視聴すると 3 日間、3 ヶ月前まで確認できます。機種変更の際は、履歴をファイルに書き出して新しい端末で読み込めます。

## Google アカウントと YouTube のデータの使い方

* 本アプリが求めるのは、YouTube アカウントの読み取り専用の権限（youtube.readonly）だけです。動画の投稿・削除、コメントの投稿、チャンネル登録の変更などは一切行いません。
* 取得した登録チャンネルの情報は、配信予定の表示と通知のためにのみ使用します。広告や分析に使用したり、第三者に提供・販売したりすることはありません。
* 本アプリには独自のアカウントを作成する機能はなく、開発者のサーバーにユーザーのアカウント情報を保存することはありません。
* 配信予定を見つけるため、表示対象のチャンネルの ID のみをサーバーに送信します。これらは特定のユーザーと紐付けずに保存しています。

本アプリが Google API から受け取った情報の使用および他のアプリへの転送は、[Google API サービスのユーザーデータに関するポリシー](https://developers.google.com/terms/api-services-user-data-policy)（限定的な使用に関する要件を含みます）に準拠します。

## データの削除

* **アクセス権の取り消し**：[Google アカウントの「サードパーティ製のアプリとサービス」](https://myaccount.google.com/connections) から、本アプリへのアクセス権をいつでも取り消せます。
* **端末内のデータ**：アプリをアンインストールすると、端末内に保存した登録チャンネル・通知設定・視聴履歴はすべて削除されます。
* 開発者のサーバーには、ユーザーを識別できる情報を保存していません。
