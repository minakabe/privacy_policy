# プライバシーポリシー

最終更新日：2026年10月29日

「Live Calendar List」（以下、「本アプリ」といいます。）は、ユーザーのプライバシーを尊重し、情報の適切な取り扱いに努めます。本プライバシーポリシーは、本アプリにおける情報の取り扱いについて定めるものです。

本アプリは個人の開発者が提供する非公式のアプリであり、YouTube および Google LLC が提供・承認・推奨するものではありません。「YouTube」は Google LLC の商標です。

## 1. 本アプリで扱う情報

### 1.1 Google アカウントの情報

本アプリでは、YouTube の登録チャンネルを取得するために Google アカウントでのログインを利用します。ログインすると、Google から以下の情報を受け取ります。

* Google アカウントの識別子（ユーザー ID）
* メールアドレス、表示名、プロフィール画像
* YouTube のデータを読み取るためのアクセストークン、および本人確認のための ID トークン

メールアドレス・表示名・プロフィール画像は、設定画面でログイン中のアカウントを表示するためにのみ利用します。

また、本アプリのサーバー機能（Firebase）を利用するため、ログイン時に Google LLC が提供する「Firebase Authentication」にもサインインします。このとき、Firebase Authentication に上記の Google アカウントの識別子・メールアドレス・表示名・プロフィール画像が登録されます。これらの情報は認証のためにのみ利用し、本アプリの開発者が広告や分析等の目的で利用することはありません。

### 1.2 YouTube のデータ（YouTube API サービス）

本アプリは YouTube API サービスを利用しています。ユーザーが許可した場合に限り、YouTube のアカウントに対する読み取り専用の権限（youtube.readonly）を使って、以下の情報を取得します。

* ユーザーが登録しているチャンネルの一覧（チャンネル ID、チャンネル名、アイコン画像など）

また、チャンネルのライブ配信予定（動画 ID、タイトル、サムネイル画像、配信予定時刻など、YouTube 上で公開されている情報）を表示します。

本アプリが求めるのは読み取り専用の権限のみです。動画の投稿・削除、コメントの投稿、チャンネル登録の変更など、ユーザーの YouTube アカウントに対する書き込みは一切行いません。

### 1.3 端末内に保存する情報

本アプリでは、以下の情報をユーザーの端末内に保存します。

* 取得した登録チャンネルの情報と、ユーザーが選んだ表示・通知の対象
* ライブ配信予定の情報（表示のためのキャッシュ）
* 通知の設定（通知のタイミングなど）
* 視聴履歴（本アプリから「YouTube で視聴する」を選んだ配信の動画 ID、タイトル、サムネイル画像、配信予定時刻、選んだ日時）。視聴履歴は 3 ヶ月を過ぎたものから自動的に削除します。
* 広告の視聴により視聴履歴の表示期間を延長した日時などの、アプリの設定

これらの情報は本アプリの機能を提供するためだけに利用し、1.4 に記載するものを除き、本アプリの開発者のサーバー等へ送信することはありません。

### 1.4 サーバーに送信・保存する情報

ライブ配信予定を検出するため、ユーザーが表示の対象とした YouTube チャンネルのチャンネル ID を、本アプリの開発者が利用するサーバー（Google LLC が提供する Firebase／Google Cloud Platform）に送信し、保存します。送信の際は、不正な利用を防ぐため Google の ID トークンをあわせて送信し、サーバー側で検証します。

また、サーバー上で YouTube API サービスを利用し、YouTube 上で公開されているライブ配信の情報（動画 ID、タイトル、サムネイル画像、配信予定時刻など）を取得して、キャッシュとして保存します。

* サーバーに保存するのは、チャンネル ID と、YouTube 上で公開されている配信予定の情報のみです。
* これらの情報を、Google アカウントの識別子やメールアドレスなど、特定のユーザーを識別できる情報と紐付けて保存することはありません。ID トークンは検証のためにのみ使用し、保存しません。
* 配信予定のキャッシュは、YouTube 側の情報に合わせて定期的に更新し、配信が終了したもの等は削除します。

### 1.5 視聴履歴のバックアップ

本アプリでは、機種変更時の移行のために、視聴履歴を JSON 形式のファイルとして書き出し・読み込みできます。

* 書き出したファイルは、ユーザーが端末の保存画面で選んだ場所（端末のストレージや、ユーザーが選んだクラウドストレージなど）にのみ保存します。
* 読み込みでは、ユーザーが端末のファイル選択画面で選んだファイルのみを読み込みます。
* 本アプリの開発者のサーバーへ視聴履歴を送信することはありません。

### 1.6 通知

ライブ配信の開始前に通知するため、端末の通知機能を利用します。通知の予約は端末内で行い、通知のための情報をサーバーへ送信することはありません。

## 2. 利用目的

取得した情報は、以下の目的にのみ利用します。

* Google アカウントによるログインと、本アプリのサーバー機能の認証
* YouTube の登録チャンネルの取得・表示
* ライブ配信予定の取得・一覧表示・カレンダー表示
* ライブ配信開始前の通知
* 視聴履歴の記録・表示・バックアップ
* 本アプリの不具合の修正、および機能の提供・改善

## 3. Google API サービスから取得した情報の取り扱い

本アプリが Google API から受け取った情報の使用および他のアプリへの転送は、[Google API サービスのユーザーデータに関するポリシー](https://developers.google.com/terms/api-services-user-data-policy)（限定的な使用に関する要件を含みます）に準拠します。

* YouTube のデータは、本アプリの機能（登録チャンネルとライブ配信予定の表示、通知）を提供するためにのみ使用します。
* YouTube のデータを広告の配信やユーザーの分析のために使用したり、第三者へ販売・提供したりすることはありません。
* 本アプリの開発者が、ユーザーの YouTube のデータを閲覧することはありません。

本アプリをご利用いただくことで、ユーザーは [YouTube 利用規約](https://www.youtube.com/t/terms) に同意したものとみなされます。YouTube API サービスにおける Google の情報の取り扱いについては、[Google プライバシー ポリシー](https://policies.google.com/privacy) をご確認ください。

## 4. 広告について

本アプリでは、Google LLC が提供する広告配信サービス「Google AdMob」を利用し、バナー広告およびリワード広告（視聴すると視聴履歴の表示期間が延長される広告）を表示します。

AdMob では、広告の配信および広告の効果測定等のため、広告 ID、端末情報、IP アドレス、アプリの利用状況等の情報が取得・利用される場合があります。また、ユーザーの同意状況や地域等に応じて、パーソナライズド広告または非パーソナライズド広告が表示される場合があります。

AdMob に YouTube のデータや Google アカウントの情報を提供することはありません。広告 ID のリセットや削除は、端末の設定（広告やプライバシーに関する項目）から行えます。Google による情報の取り扱いについては、[Google のポリシーと規約（広告）](https://policies.google.com/technologies/ads) をご確認ください。

## 5. 第三者への提供

法令に基づく場合を除き、ユーザーの情報を第三者へ提供・販売することはありません。

ただし、本アプリの機能の提供のため、以下の外部サービスを利用しています。これらのサービスにおける情報の取り扱いは、それぞれの提供元のプライバシーポリシーに従います。

* Google ログイン（Google LLC）
* YouTube API サービス（Google LLC）
* Firebase Authentication、Cloud Firestore、Cloud Functions for Firebase（Google LLC）
* Google AdMob（Google LLC）

## 6. 情報の保存期間と削除

* **端末内の情報**：本アプリをアンインストールすると削除されます。登録チャンネルの表示対象はアプリ内でいつでも変更でき、視聴履歴は 3 ヶ月を過ぎたものから自動的に削除します。
* **Google アカウントとの連携**：設定画面の「ログアウト」でログアウトできます。また、[Google アカウントのサードパーティ製アプリとサービスの管理ページ](https://myaccount.google.com/connections) から、本アプリへのアクセス権をいつでも取り消せます。取り消した後は、本アプリは YouTube のデータを取得できなくなります。
* **Firebase Authentication に登録された情報**：11 のお問い合わせ先までご連絡いただければ、登録された情報を削除します。
* **サーバーに保存されたチャンネル ID と配信予定**：特定のユーザーと紐付けずに保存しているため、個別のユーザーの情報として削除することはできません。どのユーザーからも表示の対象とされなくなったチャンネルの情報は、順次更新・削除の対象となります。

## 7. 安全管理

本アプリとサーバーとの通信は暗号化（HTTPS）して行います。サーバーのデータベースは、ユーザーのアプリから書き込めないよう設定しており、書き込みはサーバー上の処理からのみ行います。
