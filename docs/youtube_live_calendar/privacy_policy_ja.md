1. はじめに

本プライバシーポリシーは、YouTube Live Calendar（以下「本アプリ」）におけるユーザー情報の取り扱いについて定めるものです。

2. 取得する情報

本アプリでは、以下の情報を取得・利用します。

Googleアカウントに関する情報

Googleログインを利用する際、Googleから提供されるアカウント情報を利用します。

YouTubeに関する情報

ユーザーが許可した場合、YouTube Data APIを利用して、登録したYouTubeチャンネルの情報およびライブ配信予定に関する情報を取得します。

アプリ内で登録した情報

ユーザーが本アプリに登録したYouTubeチャンネル情報、ライブ配信予定情報、通知設定等を端末内に保存します。

3. 利用目的

取得した情報は、以下の目的で利用します。

Googleアカウントによるログイン
YouTubeチャンネルの登録・表示
ライブ配信予定の取得・表示
ライブ配信カレンダーの表示
ライブ配信開始前の通知
本アプリの機能提供および改善
4. 情報の保存

本アプリに登録した情報は、原則としてユーザーの端末内に保存されます。

本アプリの運営者が独自のサーバーへユーザーのYouTubeチャンネル情報やライブ配信予定を送信して保存することはありません。

5. GoogleおよびYouTube APIについて

本アプリはGoogle Sign-InおよびYouTube Data APIを利用しています。

GoogleおよびYouTubeから取得した情報は、本アプリの機能提供に必要な範囲で利用します。

6. 第三者への提供

法令に基づく場合を除き、ユーザーの情報を第三者へ提供することはありません。

7. 外部サービス

本アプリでは、以下の外部サービスを利用しています。

Google Sign-In
YouTube Data API

これらのサービスにおける情報の取り扱いについては、それぞれの提供元のプライバシーポリシーをご確認ください。

8. ユーザーによる情報の削除

ユーザーは、本アプリから登録したYouTubeチャンネル等を削除できます。

また、Googleアカウントとの連携を解除することができます。

9. 広告について

本アプリでは、Google LLCが提供する広告配信サービス「Google AdMob」を利用しています。

AdMobでは、広告の配信および広告の効果測定等のため、広告ID、端末情報、IPアドレス、アプリの利用状況等の情報が取得・利用される場合があります。

また、ユーザーの同意状況や地域等に応じて、パーソナライズド広告または非パーソナライズド広告が表示される場合があります。

Googleによる情報の取り扱いについては、Googleのプライバシーポリシーをご確認ください。

10. プライバシーポリシーの変更

本ポリシーの内容は、必要に応じて変更される場合があります。

重要な変更がある場合は、本アプリまたは本ポリシーの掲載ページ等でお知らせします。
